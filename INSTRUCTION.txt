----------------------------------------------------------------------

    npm run install-all

- Backend (Express, Socket.IO, Supabase client, Bcrypt, JWT, etc.)
- Frontend (React 19, Vite, Tailwind CSS v4, GSAP, Lucide icons, etc.)

4. STEP 3: DATABASE SETUP
----------------------------------------------------------------------
FundBridge supports TWO database modes:

OPTION A: Supabase Cloud PostgreSQL (Recommended)
-------------------------------------------------
1. Log in to your Supabase project (https://supabase.com).
2. Go to the "SQL Editor" -> Click "New query".
3. Run the SQL migration scripts in this exact order:
   - File 1: `supabase/01_schema_and_tables.sql`
     (Creates all 18 tables, relationships, indexes, and pgcrypto)
   - File 2: `supabase/02_seed_initial_data.sql`
     (Seeds 100 founders, 30 investors, 50 campaigns, default admin)
   - File 3: `supabase/03_realtime_notifications.sql`
     (Enables real-time publication & high-speed indexing)
4. Verify your database connection anytime by running:
     npm run test:db

OPTION B: Offline / In-Memory Fallback Mode (Zero-Config)
---------------------------------------------------------
- If Supabase is unavailable or credentials are omitted, the backend 
  automatically switches to the built-in catalog with 100 student 
  founders, 30 investors, 2 admins, and 50 startup campaigns.
- Data edits, milestones, proposals, and chats are automatically saved 
  locally to `backend/s3_*.json` files.

5. STEP 4: START THE APPLICATION
----------------------------------------------------------------------
To start both the Frontend and Backend together with one command:

    npm start

This runs:
- React (Vite) Frontend on:   http://localhost:5173
- Node (Express) Backend on:  http://localhost:5001

--------------------------------------------------
ALTERNATIVE: Start in Separate Terminals (Optional)
--------------------------------------------------
If you prefer separate terminal tabs for debugging:

Terminal 1 (Backend):
    npm run backend
    # or: cd backend && npm run dev

Terminal 2 (Frontend):
    npm run frontend
    # or: cd frontend && npm run dev

8. AVAILABLE NPM COMMANDS
----------------------------------------------------------------------
Run these commands from the project root directory:

- `npm start`         : Start both frontend and backend concurrently
- `npm run install-all`: Install root, frontend, and backend packages
- `npm run frontend`  : Start only the React (Vite) development server
- `npm run backend`   : Start only the Express API server with nodemon
- `npm run test:db`   : Test Supabase connection and query users table
- `npm run seed`      : Generate/update seed data JSON catalog
- `npm run build`     : Build the frontend for production deployment

9. TROUBLESHOOTING & COMMON FIXES
----------------------------------------------------------------------
Q: Port 5001 or 5173 is already in use?
A: On macOS/Linux, find and kill the process:
     lsof -ti:5001 | xargs kill -9
     lsof -ti:5173 | xargs kill -9
   Or change the port in `backend/.env` and update `frontend/.env`.

Q: Frontend fails to connect to the backend?
A: Ensure backend is running on port 5001 and `frontend/.env` contains:
     VITE_API_URL=http://localhost:5001

Q: "Cannot find module" after pulling updates?
A: Reinstall all dependencies:
     npm run install-all
